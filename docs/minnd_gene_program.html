Introduction

We obtained the pseudobulk sample that have been processed by Christina. Each sample is the sum of read count for each gene for all cells within a sequencing batch and a perturbation (including NTC). There are 107 genes targeted for Loss of function knockdown. These genes were divided into 5 gene sets. Each genes sets were perturbed and sequenced in three to four batches. After removing lowly expressed genes, we applied TMM to estimate the normalization factors.

Then we estimate the mean-variance trend of the pseudobulk count matrix while controlling for the batch effects as mixed effects. The estimation error was preserved as input for the downstream factor analysis.

Finally, we used limma::removeBatchEffect to remove batch effect while keeping the design matrix. The resulting matrix of log CPM values for 20107 genes and 402 pseudobulk samples was used for downstream analysis.

The preprocessing code is shown as below:

library(limma)
library(edgeR)
library(dream)

#### Run raw count data
load("metadata_per_celltype.Rdata")
load("GABA_raw_counts_geneset1to5.Rdata")

dge <- DGEList(counts = GABA_counts, samples = GABA_meta)

# Keep lowly-expressed genes (in terms of CPM)
keep <- filterByExpr(dge, group = GABA_meta$Loss_of_function)
dge <- dge[keep, , keep.lib.sizes = FALSE]
dge <- calcNormFactors(dge, method = "TMM")

# Compute CPM after interpolating the mean-variance trend and 
form <- ~ perturbation + donor + (1|seq_batch) + (1|seq_batch:culture_batch)
vobj <- voomWithDreamWeights(dge, form, meta)

# Remove batch effects as fixed effects while keeping the design matrix close the mixed effect model.
Yc <- limma::removeBatchEffect(
  vobj$E, batch = culture_batch, covariates = model.matrix(~ donor)[, -1],
  design = model.matrix(~ perturbation), weights = vobj$weights)

Regardless of the genes targeted, there is a nested batch structure with three layers: cell line, sequencing batch, and co-culture batch. The “batch” in the last paragraph referred to the sequencing batch. Essentially, cells within the same sequencing batch come from the same cell line. Each cell line was used in three to four sequencing batches. For each sequencing batch, there are two to four co-culture batches.

Similar to the gene program approach by Ota et al, we ran factor analysis on the gene by pseudobulk sample matrix, ignoring batch structures. Then we regressed perturbation on the “usage” of gene programs, controlling for batch effects.

Factor analysis

We ran semi-NMF with the full matrix with the package flashier. More specifically, both factors (the gene side of the program) and loadings (the sample side of the program) follow the spike and slab mixture to impose sparsity. The slab for the factors is a Normal distribution. The slab for the loadings is an Exponential distribution to enforce non-negativity. In other words, point_normal was used as prior for gene-side factors and point_exponential was used as prior for sample-side factors.

\[ Y=LF^T + E \]

where \(Y\) is the gene expression matrix, \(L\) is the sample loading, \(F\) is the factor, and \(E\) is the residual.

We standardize the expression of each gene before running the factor analysis. We also enforce gene-specific residual variance with the option var_type in flashier. We obtained 27. factors from the result.

Diagnosis of factor analysis results

The first factor captures most variance. But this is the baseline factor, capturing the grand mean of gene expression. Its sample loading was highly concentrating on 5.8. Coefficients of variation (CV) was 0.08.

After removing the first factor. PVE was more evenly distributed.

Associating sample loadings with perturbation

After obtaining the sample loading from matrix factorization and removing the six factor pointing to technical variations, we first normalized the usage across programs such that the usage for each sample sums up to one. And then we standardize the usage across samples such that it has mean=0 and std=1. Finally, we regressed all the perturbation on the loadings for each program with the following formula in lm:

\[ loading \sim perturbation \]

The perturbation was encoded as a categorical variable with the non-targeting control (NTC) as the reference. Pooling all the perturbation improved the estimation of batch effects and the loadings in NTC samples. The coefficients of perturbation indicate the change of program activity caused by the perturbation.

Since the sample loading follows exponential distribution, nominal P values from OLS is probably not calibrated. Therefore, we permuted the samples within each culture batch 10,000 times to generate a null distribution of Z score. The Z scores of all perturbations for the same factor were pooled into one null distribution. And we compared the empirically observed Z score with the null Z score to obtain the permutaiton P values for each pair of factor and perturbation. Then we applied Benjamini-Hochberg FDR control on all the permutation P values. \(\beta\) with FDR<5% was determined as statistically significant. 54 perturbations has a significant association to at least one gene program. 20 factors were associated with at least one perturbation.

Some pathway convergence or complex convergence can be observed. For example, LoF of PTEN, TSC1, NF1 converged on factor 20 and factor 6. MED23 and MED13L converged on factor 19, 27, and 10.

Enrichment analysis of the factors

We applied SuSIE-based enrichment analysis (singlecelljamboreeR::perform_gsea) to identify GO terms in biological process that can be mapped to the gene programs. The number of credible sets is ten. Any GO terms with PIP>80% is deemed significant.
